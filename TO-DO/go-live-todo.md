# Go-live: τι μένει (web)

Τελευταία ενημέρωση: 25/11/2026. Σειρά: πρώτα web, μετά mobile.
Το web είναι live στο vetly.gr (c289a71) με δοκιμαστικά δεδομένα. Το mobile είναι έτοιμο για τα πρώτα builds· λείπουν οι λογαριασμοί στα stores.

## 1. Πριν ανοίξει σε πραγματικούς κτηνιάτρους

- [ ] Νομικός έλεγχος των προσχεδίων `/terms` και `/privacy`
- [ ] Συμπλήρωση: επωνυμία, ΑΦΜ, διεύθυνση, email επικοινωνίας, πόλη δικαστηρίων, διάρκεια backups, DPO
- [ ] Αφαίρεση της σήμανσης «Προσχέδιο» και του `noindex`, προσθήκη στο sitemap
- [ ] Νέα τιμή στο `TERMS_VERSION` όταν οριστικοποιηθούν οι όροι
- [ ] Καθαρισμός των δοκιμαστικών δεδομένων από την παραγωγή
- [ ] Απόφαση για `PILOT_MODE` στο λανσάρισμα
- [ ] Η Πολιτική απορρήτου να αναφέρει τα στοιχεία της φόρμας demo

## 2. Δοκιμές που δεν έχουν γίνει

- [ ] Ροές κηδεμόνα στο live site: κράτηση από προφίλ, ακύρωση, αλλαγή ώρας, κατοικίδια, βοηθός
- [ ] Με πραγματικό email: εγγραφή κηδεμόνα → επιβεβαίωση → επιστροφή στην κράτηση
- [ ] Ανέβασμα φωτογραφίας από πραγματικό κινητό (HEIC δεν υποστηρίζεται)
- [ ] Δοκιμή επαναφοράς από backup

## 3. Server

- [ ] Caddy: HSTS, όριο μεγέθους αιτήματος (~6 MB), CSP και μακρύ cache στο `/uploads`
- [ ] `SENTRY_DSN` αν θέλουμε παρακολούθηση σφαλμάτων
- [ ] Δικός μας mail server (SPF, DKIM, DMARC, reverse DNS, πόρτα 25)· μέχρι τότε μένει το Resend, που δουλεύει

## 4. Μικρά υπόλοιπα στον κώδικα

- [ ] Εικόνα κοινοποίησης 1200×630 (τώρα χρησιμοποιείται το λογότυπο)
- [ ] Email εκτός αιτήματος και για αξιολογήσεις, υπενθυμίσεις, προσκλήσεις, επιβεβαίωση email
- [ ] Η εφημερία στο dashboard κηδεμόνα κάνει polling και με κρυφή καρτέλα
- [ ] CSP και `X-Frame-Options` για τις σελίδες του Next
- [ ] Όρια αιτημάτων σε κοινό store αν τρέξουμε πάνω από έναν worker
- [ ] Οι ημερομηνίες στη φόρμα άδειας ακολουθούν τη γλώσσα του browser (mm/dd/yyyy σε αγγλικό)

## 5. Ανοιχτές αποφάσεις προϊόντος

- [ ] Χρέωση/συνδρομή κτηνιάτρων (δεν υπάρχει)
- [ ] Πολλοί γιατροί ανά ιατρείο (τώρα ένας λογαριασμός = ένα ιατρείο)
- [ ] Υπενθυμίσεις με SMS/Viber

## 6. Μετά το web (Φάση 3)

- [ ] Λογαριασμοί Apple Developer και Google Play Console (ιδιώτης ή εταιρεία με D-U-N-S)
- [ ] Λογαριασμός Expo, πρώτο EAS build, δοκιμή σε πραγματικό κινητό
- [ ] Push: κλειδί APNs (Apple) και Firebase (Google)
- [ ] Google: κλειστή δοκιμή με 12+ testers για 14 ημέρες πριν τη δημόσια διάθεση
- [ ] Σελίδα στα stores: περιγραφή, screenshots, App Privacy / Data safety, λογαριασμός για τους reviewers
- [ ] Ο βοηθός μιλά στον πληθυντικό, η εφαρμογή στον ενικό
- [ ] Ευπάθεια node-forge στα εργαλεία του Expo (DEPENDENCY_SECURITY.md)
- [ ] Push για κτηνιάτρους στο backend και εφαρμογή κτηνιάτρου
- [ ] Universal / app links
- [ ] Tickets στο Notion (μόνο με έγκριση)
- [ ] Χάρτης: δικά μας tiles (Protomaps) αντί για OpenFreeMap, αν χρειαστεί
