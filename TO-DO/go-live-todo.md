# Go-live: τι μένει (web)

Τελευταία ενημέρωση: 11/11/2026. Σειρά: πρώτα web, μετά mobile.
Ο κώδικας των Φάσεων 1 και 2 είναι γραμμένος. Ό,τι μένει είναι server, νομικά, δοκιμές και mobile.

## 1. Πριν το deploy (server)

- [ ] `SECRET_KEY` παραγωγής τουλάχιστον 32 χαρακτήρες — αλλιώς το backend δεν ξεκινά
- [ ] `ANTHROPIC_API_KEY` στο `.env` του server
- [ ] `ADMIN_EMAILS` στο `.env` του server (email ήδη εγκεκριμένου κτηνιάτρου που θα εγκρίνει τους νέους)
- [ ] Απόφαση για `PILOT_MODE` στο λανσάρισμα
- [ ] Mail server: SPF, DKIM, DMARC, reverse DNS, άνοιγμα πόρτας 25 από τη Hetzner (repo `vps-manager`)
- [ ] `EMAIL_PROVIDER=smtp` και `SMTP_*` στο `.env`, δοκιμή με πραγματική αποστολή (μέχρι τότε μένει το Resend)
- [ ] `SENTRY_DSN` αν θέλουμε παρακολούθηση σφαλμάτων
- [ ] Deploy στο moltbot — τέσσερα νέα migrations (`e1f2a3b4c5d6` → `f2a3b4c5d6e7` → `5c8f2b71d9e4` → `7d1e5a90c3b2`)
- [ ] Ο reminder worker να τρέχει (κάνει και την οριστική διαγραφή κατοικιδίων μετά από 30 ημέρες)
- [ ] Έλεγχος ότι το `TZ=Europe/Athens` ισχύει μέσα στα containers
- [ ] Δοκιμή επαναφοράς από backup
- [ ] Caddy: HSTS, όριο μεγέθους αιτήματος (~6 MB), CSP και μακρύ cache στο `/uploads`

## 2. Νομικά

## 3. Δοκιμές που δεν έχουν γίνει

- [ ] Με κλικ: αλλαγή κωδικού κτηνιάτρου, κλείσιμο λογαριασμού, εξαγωγή δεδομένων, δημιουργία άδειας, ολοκλήρωση επίσκεψης με ποσό
- [ ] Ανέβασμα φωτογραφίας από πραγματικό κινητό (HEIC δεν υποστηρίζεται)

## 4. Μικρά υπόλοιπα στον κώδικα

- [ ] Πεδίο τιμής κατά την έγκριση αιτήματος (το backend το δέχεται, δεν υπάρχει στο UI)
- [ ] Ένα `window.confirm` στο `VetAssistantWorkspace.tsx`
- [ ] Οι υπενθυμίσεις που δημιούργησε κτηνίατρος δεν ακυρώνονται όταν κλείσει τον λογαριασμό του
- [ ] Εικόνα κοινοποίησης 1200×630 (τώρα χρησιμοποιείται το λογότυπο)
- [ ] Email εκτός αιτήματος και για αξιολογήσεις, υπενθυμίσεις, προσκλήσεις, επιβεβαίωση email
- [ ] Η εφημερία στο dashboard κηδεμόνα κάνει polling και με κρυφή καρτέλα
- [ ] CSP και `X-Frame-Options` για τις σελίδες του Next
- [ ] Όρια αιτημάτων σε κοινό store αν τρέξουμε πάνω από έναν worker
