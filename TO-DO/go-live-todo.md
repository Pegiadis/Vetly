# Go-live: τι μένει (web)

Τελευταία ενημέρωση: 10/11/2026 (βράδυ). Σειρά: πρώτα web, μετά mobile.

## 1. Πριν το deploy (server)

- [ ] `SECRET_KEY` παραγωγής τουλάχιστον 32 χαρακτήρες — αλλιώς το backend δεν ξεκινά πλέον
- [ ] `ANTHROPIC_API_KEY` στο `.env` του server
- [ ] `ADMIN_EMAILS` στο `.env` του server (email ήδη εγκεκριμένου κτηνιάτρου που θα εγκρίνει τους νέους)
- [ ] Mail server: SPF, DKIM, DMARC, reverse DNS, άνοιγμα πόρτας 25 από τη Hetzner (repo `vps-manager`)
- [ ] `EMAIL_PROVIDER=smtp` και `SMTP_*` στο `.env` του server, δοκιμή με πραγματική αποστολή
- [ ] `SENTRY_DSN` αν θέλουμε παρακολούθηση σφαλμάτων
- [ ] Deploy στο moltbot (έχει migration `e1f2a3b4c5d6`) και έλεγχος στο vetly.gr
- [ ] Έλεγχος ότι το `TZ=Europe/Athens` ισχύει μέσα στο container

## 2. Νομικά

- [ ] Νομικός έλεγχος των προσχεδίων `/terms` και `/privacy`

## 3. Ασφάλεια (υπόλοιπα)

## 4. UI (υπόλοιπα)

- [ ] Μακρύ όνομα κτηνιάτρου σπάει άσχημα στην κάρτα της κράτησης στο κινητό
- [ ] Ελληνικά μηνύματα λάθους και στο mobile app
